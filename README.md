# MY COFFEE CO.

A modern and responsive coffee ecommerce homepage built using React, Parcel, and Tailwind CSS. This project focuses on: 
Premium UI/UX, 
Lightweight performance, 
Responsive ecommerce layout, 
Clean modern design, 
Smooth animations without heavy libraries
